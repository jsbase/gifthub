# wishy

One person's list of gift ideas, shared with the specific people who will buy from it, so nobody buys the same present twice.

## Language

**Idea**:
One thing on a list that the owner would like to be given. Readers see it called a wish (Wunsch, желание); `Gift` is only the name of its model in the code.
_Avoid_: gift, item, wish (outside reader-facing copy)

### Marks

**Mark**:
The shared record on an idea that it has been bought, set by a buyer or by the owner. One per idea, seen by everyone who can see the list, and never naming who set it.
_Avoid_: tick, purchase flag, collected

**Open idea**:
An idea that carries no mark.
_Avoid_: unbought idea, available idea

**Bought idea**:
An idea that carries a mark, whoever set it.
_Avoid_: purchased idea, collected idea, ticked idea

### Transfer

**Copy**:
A new open idea with the same title, note and address, put on another of the owner's lists while the original stays where it is. Only an open idea can be copied.
_Avoid_: duplicate, clone

**Move**:
The idea itself, put on another of the owner's lists. It keeps its mark.
_Avoid_: relocate, transfer (for one verb; transfer is the name for both)
